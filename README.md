# 📊 Анализ кредитного риска (Индия)

## 📌 Описание проекта
Данный проект представляет собой комплексный анализ кредитного портфеля для выявления ключевых факторов риска дефолта. Работа включает в себя полный цикл обработки данных: загрузку и очистку сырых данных, создание новых признаков (Feature Engineering), разведочный анализ (EDA), а также построение интерактивного дашборда для визуализации результатов.

## 🛠 Используемые технологии
- **Python 3** (Pandas, NumPy) — для обработки и анализа данных.
- **Tableau Desktop Public** — для создания интерактивного дашборда.
- **GitHub Desktop** — для хранения и версионирования проекта.

## 📂 Структура проекта
| Файл | Описание |
|------|----------|
| `india_personal_loan_default_risk_2026.csv` | Исходные сырые данные (25 000+ записей) |
| `анализ_скрипт.py` | Python-скрипт с полным кодом обработки и анализа данных |
| `loan_data_for_tableau.csv` | Чистые данные, подготовленные для загрузки в Tableau |
| `preview_aggregated_data.xlsx` | Контрольные агрегированные данные (для проверки расчетов) |
| `Дашборд.twb` | Готовый интерактивный дашборд в Tableau |

## 📊 Ключевые выводы (Insights)
1. **Кредитный скор (CIBIL)** — самый сильный фактор риска. У клиентов с CIBIL < 600 уровень дефолта составляет **13.2%**, а у клиентов с хорошим скором (700-800) — всего **0.4%**.
2. **Просрочки**: Клиенты, у которых были просрочки в прошлом, дефолтят значительно чаще.
3. **Тип занятости**: Владельцы бизнеса являются самой рискованной группой (**7.4%** дефолтов).
4. **Цель кредита**: Свадьбы (**6.5%**) и консолидация долгов (**6.6%**) — самые рискованные цели кредитования.
5. **География**: Самый высокий уровень дефолта наблюдается в штатах Раджастан (7.1%) и Андхра-Прадеш (6.8%).

## 📈 Как воспроизвести проект
1. **Запуск кода (Python):**
   - Установите зависимости: `pip install pandas numpy`
   - Запустите скрипт: `python анализ_скрипт.py`
2. **Визуализация (Tableau):**
   - Откройте файл `Дашборд.twb` в программе Tableau Desktop.
   - Для обновления данных подключите файл `loan_data_for_tableau.csv` через **Data Source** (Источник данных).
